# 🎮 Simon Says Game

A fun and interactive Simon Says memory game built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🎯 Random color sequence generation
- 📈 Progressive levels
- ✨ Button flash animations
- 🧠 Memory-based gameplay
- ❌ Game Over detection
- 🎨 Responsive and attractive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Press any key to start the game.
2. Watch the color that flashes.
3. Click the colors in the same sequence.
4. Each correct round increases the level.
5. One wrong click ends the game.
